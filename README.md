GIF display for rp2040/rp2 with a ST7789 display or any display; other displays require code modification.  

How it works: press the BOOTSEL button and run the Python script in the .uf2 file, then copy the lib folder to the Pi Pico along with the code.py file.  

How it works: paste GIF files into the main directory and that's it. Note: I recommend first running it through Thonny and testing if the 360 MHz clock works — such a high speed may not work on every Pi Pico.
